# Mamushka | Sistema de gestión

Desarrollé esta aplicación para ayudar con la gestión del negocio familiar de ropa y calzado. La idea surgió de una necesidad real: tener en un solo lugar la información de ventas, créditos, pagos, gastos y compras.

## Funcionalidades

- Registro de ventas y medios de pago.
- Gestión de créditos personales y seguimiento de saldos.
- Registro de pagos de clientes.
- Control de gastos y compras.
- Resúmenes de ventas y gastos.
- Generación de comprobantes y mensajes para compartir por WhatsApp.

## Tecnologías

- **HTML, CSS y JavaScript:** interfaz y funcionalidades del lado del cliente.
- **Google Apps Script:** lógica del servidor y procesamiento de las operaciones.
- **Google Sheets:** almacenamiento y organización de los datos.
- **Claude:** asistencia durante el desarrollo, la implementación de funcionalidades y la resolución de problemas.

## Cómo lo desarrollé

Fui construyendo la aplicación de forma incremental. Empecé con una funcionalidad sencilla, la probé y después fui agregando nuevas funciones según las necesidades del negocio.

Trabajé con Claude como asistente durante el proceso, revisando los resultados, probando cambios y corrigiendo errores a medida que aparecían. El objetivo fue pasar de una idea a una herramienta que pudiera utilizarse en el día a día.

## Estado actual

La aplicación está en uso y sigo trabajando en mejoras y correcciones a partir de las necesidades que aparecen.
